# YouTube Downloader (local)

![Python](https://img.shields.io/badge/python-3.11%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Scope](https://img.shields.io/badge/scope-100%25%20local-lightgrey)

A local app to download YouTube videos as MP4 at the resolution you pick, and to
generate text transcripts. It runs only on your machine (`localhost`) — nothing is
exposed to the internet.

## About this project

Written for **personal, local use**, and published because it may be useful to
other people. It is worth being explicit about what it is not:

- **Not a product**, and not commercial.
- **Not built to be hosted on the web.** It has no authentication, no rate
  limiting and no defenses of any kind. The server refuses by default any
  connection that does not come from the machine itself — see
  [Why local only](#why-local-only).
- **No warranty and no support.** It is a personal utility shared as-is. Issues
  and forks are welcome, but I make no promise of ongoing maintenance.

## System requirements

- **Python 3.11+**
- **ffmpeg** — required to merge audio and video at 1080p and above
  (`brew install ffmpeg`)
- **A JavaScript runtime** (Node, Deno or Bun) — YouTube requires solving a JS
  challenge to sign media URLs. Without one, downloads fail with
  `HTTP Error 403: Forbidden` (`brew install node`)

`yt-dlp` is installed along with the dependencies below.

> The install commands use Homebrew (macOS). On Linux, swap in your
> distribution's package manager — for example `sudo apt install ffmpeg nodejs`.

## Install

```bash
git clone https://github.com/zennitty/youtube-downloader-local.git
cd youtube-downloader-local
pip install -r requirements.txt
```

Using a virtual environment before `pip install` is recommended:

```bash
python3 -m venv .venv && source .venv/bin/activate
```

## Run

```bash
python3 run.py
```

Then open **http://127.0.0.1:8000** in your browser. Paste the link, click
**Fetch**, pick the quality and click **Download**. The browser asks where to
save it.

To change the port: `python3 run.py --port 9000`.

## Transcripts and subtitles

Below the resolution list there is a **Transcript / subtitles** section, which
produces a `.txt` file with the spoken text of the video. It works as a cascade:

1. **If the video has subtitles** (official or auto-generated by YouTube), the
   text is extracted from them — this takes seconds.
2. **If it has none**, the audio is downloaded and transcribed locally with
   Whisper (`faster-whisper`, `small` model). That takes **a few minutes** —
   roughly half the video's duration.

The selector lets you choose the language, or force transcription from audio even
when subtitles exist (slower, sometimes more accurate).

On the first audio transcription, `faster-whisper` downloads the model (a few
hundred MB). That happens once; afterwards it is cached.

### Technical terms field

The **Technical terms in the video** field noticeably improves Whisper's output
on jargon. Without it, "subagents" tends to come out as nonsense; listing the
terms makes the model spell them correctly. It only affects transcription from
audio — the ready-subtitle path ignores it.

## Why local only

The app downloads videos using the network identity of whoever hosts it, and it
has no authentication and no usage limits. Exposed to the internet, it becomes a
public download service running on your IP, with your name on the record.

That is why `run.py` always binds to `127.0.0.1`, and the server has a middleware
that answers **403** to any request coming from outside the machine — including
when someone starts it manually with `--host 0.0.0.0`. The behavior is tested:

```bash
python3 test_loopback.py
```

If you adapt this for another use, what happens next is your responsibility.

## When a video will not download

YouTube changes its encryption often, and that breaks extraction. If a link stops
working, update yt-dlp:

```bash
pip install -U yt-dlp
```

If the error is **`HTTP Error 403: Forbidden`**, it is almost always one of two
causes: an outdated yt-dlp, or no JavaScript runtime installed. Update yt-dlp
with the command above and confirm that `node -v` responds.

## Responsible use

This is a tool for **personal use**: download only your own videos, freely
licensed ones, or content you are authorized to download. Downloading third-party
content without authorization violates YouTube's Terms of Service and possibly
copyright law in your country.

## Layout

| File | Role |
|---|---|
| `run.py` | Entrypoint; starts the server bound to `127.0.0.1` |
| `server.py` | FastAPI routes and job orchestration |
| `downloader.py` | yt-dlp wrapper: formats, downloads, subtitles and audio |
| `transcriber.py` | Whisper and VTT-to-text conversion |
| `jobs.py` | In-memory registry of transcription jobs |
| `static/index.html` | Web interface (no build step) |
| `test_loopback.py` | Verifies the local-access lock |
